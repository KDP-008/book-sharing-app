# Requirements

- ### As an user, I should be able to

    > logon to the app using registered details
    > create a new account using my email ID
    > reset the password if I don't remember it.
    > see appropriate message if I am not authenticated

    > choose favorite genre and author    
    > see the books I own
    > see the borrowers of my books
    > see the books I have borrowed
    > receive notifications with regards to return date of the book
    > search the book I am interested to borrow (by title, by author and by genre)
    > add book(s) to the cart and checkout, if available
    > agree on a book delivery method (courier only)
