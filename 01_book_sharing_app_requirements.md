# Requirements

- ### As an user, I should be able to

    > logon to the app using my gmail or facebook accounts

    > create a new account using my email ID

    > reset the password if I don't remeber it

    > see appropriate message if I am not authenticated

    > temporarily pause my account

    > delete my account forever

    > choose favorite genre and author
    
    > see the books I own

    > see the borrowers of my books

    > see the books I have borrowed

    > receive notifications with regards to return date of the book

    > request return date extension of a book

    > search the book I am interested to borrow (by title, by author and by genre)
    
    > mark the book as favorite

    > put the request for a specific book if not available 

    > add book(s) to the cart and checkout, if available

    > add book(s) to the wishlist if not available for borrowing currently

    > send message to the book owner

    > agree on a book delivery method (online for e-books, courier or in person for hard cover)

    > rate and feedback on the book

    > approve/reject borrow request

    > block/unblock users

- ### As an user, it would be good to

    > see recommendations based on my interest & past borrowings
    
    > see latest books of auther/genre I follow

    > have an option to create a book club (by genre/author)

    > have an option for users to organize events
